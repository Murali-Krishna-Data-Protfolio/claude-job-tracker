Data workflow — English-only job tracker

One daily run: pull listings from every enabled source, drop what's already tracked, verify each new job is genuinely English-speaking, write the result to Excel, then fan it out to phone, browser and inbox.

Fail-closed, not fail-open. A job reaches the tracker only when Claude actively confirms is_english_role: true at ≥ threshold confidence. Any classifier error now excludes the job — it used to include it by default, which is how French-only listings were slipping through.
